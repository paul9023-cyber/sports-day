# 🏆 우리동네 체육대회

## 📌 두 가지 실행 방법

| 방법 | 추천 대상 | 세팅 시간 | PC 필요? |
|------|-----------|-----------|----------|
| **A. 로컬 PC** | Windows PC가 있고 대회 동안 켜둘 수 있음 | 30초 | ✅ |
| **B. 클라우드** | PC 없이 패드·휴대폰만으로 진행 | 15분 (1회) | ❌ |

→ **클라우드 배포는 [`배포_가이드.md`](./배포_가이드.md) 참고**  
→ **로컬 PC 실행은 아래 계속**

---

## 🚀 로컬 PC 쓰는 법 (30초)

### 1️⃣ 본부 PC에서
```
run.bat 더블클릭
```
- 검은 창이 열리고 브라우저가 자동으로 뜸
- **최초 1회**만 `cloudflared.exe` 자동 다운로드 (~40MB, 약 1분)
- 홈 화면 하단 **"📱 휴대폰으로 접속하기"** 버튼을 누르면 QR 코드가 표시됨

### 2️⃣ 18개 반 휴대폰에서
- 휴대폰 **카메라 앱**을 실행 → PC 화면의 QR 스캔 → 브라우저 열림
- 또는 QR 아래 URL을 직접 입력
- 화면 우측 상단 → **"홈 화면에 추가"** 하면 아이콘이 생겨 앱처럼 씀

### 3️⃣ 대회 진행
- **본부 PC** — 학교명 저장 → 종목 추가 → "실시간 현황" 탭에서 점수 확인
- **심판 휴대폰** — 자기 반 선택 → 종목 선택 → 점수/기록 입력 → 제출
- 모든 기기에 **즉시 반영됨**

### 4️⃣ 끝내려면
- 검은 창을 닫거나 **Ctrl+C**
- 데이터는 `data.json`에 저장되어 다음 실행 시에도 유지됨

## 📶 두 가지 접속 방법

홈 화면 "📱 휴대폰으로 접속하기" 버튼을 누르면 2개 탭이 있습니다.

### ① 📶 데이터망 (어디서든) **— 추천**
- PC가 **인터넷에 연결**되어 있기만 하면 됨
- 휴대폰은 **LTE/5G 데이터** 또는 **아무 Wi-Fi**에서 접속 가능
- 운동장·공원 등 Wi-Fi 없는 야외 행사에 최적
- Cloudflare 무료 터널 사용 (가입·도메인 불필요)
- URL은 `https://xxx-xxx.trycloudflare.com` 형태 (HTTPS)
- ⚠ `run.bat` 을 다시 실행할 때마다 **URL이 바뀝니다** (QR 새로 공유)

### ② 📡 같은 Wi-Fi (인터넷 안 써도 됨)
- PC와 휴대폰이 **같은 공유기**에 연결되어야 함
- 인터넷이 안 되는 장소에서도 동작 (로컬 네트워크만으로)
- URL은 `http://192.168.x.x:8080` 형태
- 처음 접속 시 PC에 **방화벽 허용 팝업** → "액세스 허용" 클릭

## ✅ 꼭 기억할 것

| 상황 | 해결 |
|------|------|
| QR 스캔해도 "주소 생성 중..." 상태 | 최초 1회는 cloudflared 다운로드 대기 (~1분). 이후에는 10초 내외 |
| "공개 주소 생성 실패" | PC 인터넷 연결 확인, Windows Defender가 `cloudflared.exe`를 차단했는지 확인 |
| 데이터망으로 접속 안 됨 | 데이터망은 매번 URL이 바뀌니 **최신 QR**을 다시 스캔 |
| Wi-Fi 탭 방화벽 경고 | **"액세스 허용"** 클릭 |
| 포트 8080이 이미 사용 중 | `app.py` 파일을 열어 `PORT = 8080`을 `8081`로 변경 |
| Python이 없다는 에러 | https://www.python.org/downloads/ 에서 설치, "Add Python to PATH" 체크 |
| 터널 없이 쓰고 싶음 | `run.bat` 대신 `run-wifi-only.bat` 사용 (아래) |

## 📂 파일 구조

```

├─ run.bat              ← 더블클릭해서 실행
├─ app.py               ← 서버 프로그램

├─ index.html           ← 홈 (본부/심판 선택)

├─ css/style.css
├─ js/
│   ├─ api.js           ← 서버 통신
│   ├─ common.js
│   ├─ home.js
│   ├─ hq.js
```

## 🎯 기능

### 본부
- 학교 이름 저장 (모든 심판 기기에 실시간 반영)
- 종목 추가 / 이름수정 / 삭제
- 종목별 점수 방식 선택
  - **점수**: 10~180점, 10점 단위
  - **Time lap**: 분:초.소수점
- **실시간 현황**: 어느 반이 입력했는지 초록색으로 표시 + 종목별 등수표
- **종합 등수**: 모든 종목 합산 순위 (1등=18점, 2등=17점… 방식)
- 점수만 초기화 / 전체 초기화

### 심판
- 첫 실행 시 자기 반 선택(1~18반) → 이 기기는 그 반으로 고정
- 본부가 등록한 종목 목록 자동 표시
- **점수 입력**: 자물쇠 3D 회전 휠 피커, 진동 피드백
- **타임랩**: 큼직한 원형 시작/끝 버튼, 소수점 2자리까지
- 기록 수정/삭제 가능

### 동기화
- 어느 한 기기에서 바뀌면 **모든 기기에 즉시** 반영 (Server-Sent Events)
- PC와 같은 Wi-Fi만 있으면 인터넷 없이도 동작

## ⚙ 반 개수 바꾸기

기본은 18반입니다. 다르게 하려면:
- `app.py` 파일의 `"totalClasses": 18` 숫자를 수정하거나
- 본부가 처음 한 번만 API로 설정(고급): `POST /api/total-classes { "n": 20 }`
- 또는 `data.json`에서 `totalClasses` 값을 수정하고 서버 재시작
